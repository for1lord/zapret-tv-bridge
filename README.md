# Zapret TV & Mobile Bridge

Локальный сетевой шлюз и HTTP/PAC-прокси для подключения Smart TV (LG webOS, Samsung Tizen, Android TV, Apple TV), смартфонов (iPhone, iPad, Android) и Telegram к Zapret на вашем компьютере.

Программа работает в фоновом режиме без лишних консольных окон, управляется через единый интерфейс в стиле Zapret и **не требует установки Python** на компьютере пользователя.

---

## Быстрый старт (Управление через 1 файл)

1. Скачайте архив `zapret-tv-bridge-v1.06.zip` из раздела Releases и распакуйте в любую папку.
2. Запустите единственный файл управления — **`service.bat`** (запустится от имени администратора).
3. В открывшемся удобном меню:
   - Нажмите **`1`** — программа предложит список стратегий Zapret (например, введите **`12`** для выбора популярной стратегии `general (ALT12)`). После этого автоматически установятся и запустятся как служба Zapret, так и локальный шлюз (Bridge), а также откроются необходимые порты (8080, 1443) в Брандмауэре Windows.
   - Нажмите **`3`**, чтобы просмотреть статус работы и готовые ссылки/адреса для ваших устройств.
   - Нажмите **`4`**, чтобы включить тихий автозапуск при старте Windows.
   - Нажмите **`2`**, если потребуется полностью остановить и удалить службы.

> [!NOTE]
> Автономный исполняемый файл `ZapretTVBridge.exe` компилирован для 64-битной Windows и не требует установленного Python или внешних библиотек.

## Настройка подключаемых устройств

### 1. Smart TV (LG webOS, Samsung Tizen, Android TV, Apple TV)
1. Откройте параметры Wi-Fi сети на телевизоре.
2. Перейдите в расширенные параметры и включите пункт «Прокси (HTTP)».
3. Укажите IP-адрес вашего компьютера и порт `8080` (эти данные отображаются в пункте 3 меню `service.bat` и в шапке окна).

### 2. iPhone и iPad
1. Откройте «Настройки» -> «Wi-Fi» -> нажмите значок `(i)` рядом с вашей домашней сетью.
2. В самом низу выберите «Настройка прокси» -> переключите на «Автоматически».
3. В поле URL вставьте адрес: `http://<IP-компьютера>:8080/proxy.pac`.

### 3. Telegram (Смартфоны и ПК)
1. На телефоне откройте статус-страницу `http://<IP-компьютера>:8080/`.
2. Нажмите кнопку «Подключить в Telegram» и подтвердите добавление MTProto-подключения.

### 4. Игры (Brawl Stars и Clash Royale на iOS)
1. На странице `http://<IP-компьютера>:8080/` нажмите «Скачать профиль для iOS».
2. Перейдите в «Настройки» iPhone -> «Профиль загружен» -> «Установить».

## Меню менеджера (`service.bat` v1.06)

```text
==================================================
ZAPRET TV & MOBILE BRIDGE MANAGER v1.06
==================================================
Служба Zapret:         [RUNNING - general (ALT12)]
Шлюз для ТВ/Мобильных: [RUNNING - PID: ...]
Адрес шлюза:           http://192.168.0.x:8080/
PAC URL:               http://192.168.0.x:8080/proxy.pac
Smart TV:              IP 192.168.0.x  Port 8080
Папка программы:       C:\zapret-tv-bridge\
--------------------------------------------------

:: УПРАВЛЕНИЕ СЛУЖБАМИ
   1. Установить и запустить службы [Выбор стратегии Zapret]
   2. Остановить и удалить службы
   3. Проверить статус и адреса для подключения (ТВ / Смартфон)

:: НАСТРОЙКИ
   4. Автозагрузка Windows              [enabled / disabled]
   5. Открыть веб-панель в браузере
--------------------------------------------------
   0. Выход
--------------------------------------------------
```

## Вспомогательные утилиты в комплекте

В состав архива входят специальные системные скрипты для решения типовых ситуаций:

* **`stop_old_services.bat`** — полная остановка и удаление старых версий. Если на компьютере ранее использовались другие версии, этот скрипт останавливает фоновые процессы, удаляет старые службы (`zapret`, `WinDivert`, `wintun`), очищает автозагрузку и освобождает порты `8080` и `1443`.
* **`restore_network_defaults.bat`** — возвращает сетевые параметры Windows, адаптеров и DNS к стандартному заводскому состоянию.
* **`fix_browsers.reg`** — мгновенный файл реестра в два клика, который очищает системные политики браузеров (Edge, Chrome, Yandex) и гарантирует прямое подключение без зависших настроек.

## Решение частых вопросов

* **На ТВ или телефоне нет интернета:** убедитесь, что компьютер и устройство подключены к одной локальной сети роутера, а в настройках роутера выключена опция «Изоляция клиентов» (AP Isolation).
* **Компьютер переходит в спящий режим:** для непрерывной работы шлюза в схеме электропитания Windows рекомендуется выбрать режим постоянной работы без сна.
* **Антивирус или Брандмауэр:** скрипт `service.bat` автоматически добавляет разрешающие правила для портов 8080 и 1443. Если используется сторонний фаервол, разрешите входящие TCP-подключения к этим портам.
