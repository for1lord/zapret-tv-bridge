# Zapret TV & Mobile Bridge

Локальный сетевой шлюз и HTTP/PAC-прокси для подключения Smart TV (LG webOS, Samsung Tizen, Android TV, Apple TV), смартфонов (iPhone, iPad, Android) и Telegram к Zapret на вашем компьютере.

Программа работает в фоновом режиме без консольных окон, управляется через единый интерфейс в стиле Zapret и **не требует установки Python** на компьютере пользователя.

---

## Быстрый старт (Управление через 1 файл)

1. Скачайте архив `zapret-tv-bridge-v1.01.zip` из раздела Releases и распакуйте в любую папку.
2. Запустите единственный файл для настройки — **`service.bat`** (запустится от имени администратора).
3. В открывшемся интерактивном меню:
   - Нажмите **`1`**, чтобы автоматически настроить Брандмауэр Windows (порты 8080 и 1443).
   - Нажмите **`2`**, чтобы запустить службу моста в тихом фоновом режиме.
   - Нажмите **`5`**, чтобы увидеть готовые ссылки и параметры подключения для ваших устройств.

*Примечание: Вы также можете запустить автономный исполняемый файл `bin\ZapretTVBridge.exe` напрямую — он полностью автономен и не требует установленного Python.*

## Настройка устройств

### Smart TV (LG webOS, Samsung Tizen, Android TV, Apple TV)
1. Откройте настройки сети Wi-Fi на телевизоре.
2. Перейдите в расширенные параметры и включите «Прокси (HTTP)».
3. Укажите IP-адрес вашего компьютера и порт `8080` (эти данные отображаются в пункте 5 меню `service.bat`).

### iPhone и iPad
1. Откройте «Настройки» -> «Wi-Fi» -> нажмите значок (i) рядом с вашей домашней сетью.
2. Внизу выберите «Настройка прокси» -> «Автоматически».
3. В поле URL вставьте адрес: `http://<IP-компьютера>:8080/proxy.pac`.

### Telegram
1. На телефоне откройте статус-страницу `http://<IP-компьютера>:8080/`.
2. Нажмите кнопку «Подключить в Telegram» и подтвердите добавление прокси.

### Brawl Stars и Clash Royale (iOS)
1. На странице `http://<IP-компьютера>:8080/` нажмите «Скачать профиль для iOS».
2. Перейдите в «Настройки» iPhone -> «Профиль загружен» -> «Установить».

```text
==================================================
Status:    [RUNNING] (PID: ...)
Address:   http://192.168.0.x:8080/
PAC URL:   http://192.168.0.x:8080/proxy.pac
Smart TV:  IP 192.168.0.x  Port 8080
--------------------------------------------------

:: SERVICE
   1. Install Service / Firewall Rules
   2. Start Bridge (Background)
   3. Stop Bridge
   4. Restart Bridge
   5. Check Status & Connection URLs

:: SETTINGS & AUTORUN
   6. Windows Startup              [enabled / disabled]
   7. Generate New Telegram MTProto Key
   8. Open Domain Routing Lists Folder

:: TOOLS & LOGS
   9. Open Web Dashboard in Browser
   10. View Live Logs (tv_proxy.log)
   11. Run Diagnostics & DoH Latency Test

--------------------------------------------------
   0. Exit
--------------------------------------------------
```

## Решение частых вопросов

- **На ТВ или телефоне нет интернета:** убедитесь, что компьютер и устройство подключены к одной Wi-Fi сети, а в настройках роутера выключена изоляция клиентов (AP Isolation).
- **Компьютер уходит в спящий режим:** для постоянной работы моста в параметрах питания Windows рекомендуется отключить переход в спящий режим.
